## 1. 最适合你的 MemOS 方案

MemOS 为 AI 应用提供了**两种**"记忆"解决方案，满足从快速验证到生产级部署的全场景需求：

*   MemOS 云平台 ——简化开发，轻松管理：5分钟内一键使用云服务，适合 AI 应用快速搭建与迭代。

*   MemOS 开源方案 —— 自主部署，完全可控：部署到自有环境，根据业务需求二次开发与深度集成。

*   **混合部署模式** —— 灵活组合：核心业务数据本地化，非敏感场景接入云端，兼顾合规与成本。

> _无论是 云服务 还是 开源框架，MemOS 都能让你的 AI 轻松获得持久记忆。_


## 2. 功能对比

| 功能 | MemOS 云平台 | MemOS 开源方案 |
|------|-------------|--------------|
| 部署难度 | 极低，5 分钟上线 | 需自行配置环境 |
| 数据存储位置 | 云端（可选私有化） | 完全本地 |

| SLA 保障 | 有 | 无 |
| 社区支持 | 有 | 有 |
| 商业支持 | 有 | 无 |


## 3. 选择指南

### 选择 MemOS 云平台

*   **快速落地**：仅需几分钟，即可让你的 AI 应用具备自带记忆。你可以专注于业务逻辑与功能实现，无需投入时间维护复杂的存储与记忆管理体系。

*   **零成本验证**：提供充足的免费试用额度，帮助你以最低成本验证方案可行性与产品效果。

*   **日志与监控**：在控制台中实时查看调用日志，获取完整的调用链分析，便于调试、监控与性能优化。

### 选择 MemOS 开源方案

*   **数据主权**：所有记忆数据存储在你的私有环境中，满足严格的数据合规要求。

*   **自定义配置**：可自由选择 LLM 提供商、推理后端、部署策略等，实现更高的灵活性与可控性。

*   **代码扩展**：可直接修改代码库，按需扩展自定义功能，并将改进贡献回社区。

*   **离线部署**：支持完全离线的内网环境，适合对网络隔离有要求的场景。

### 不适合开源方案的场景

> _如果你的团队没有专职运维人员，或项目处于早期验证阶段，建议优先使用云平台。_


## 4. 快速接入示例

云平台接入只需三步：

```python
from memos import MemOSClient

# 1. 初始化客户端
client = MemOSClient(api_key="your_api_key")

# 2. 创建用户记忆
client.memory.add(
    user_id="user_123",
    content="用户偏好：喜欢简洁的回答风格"
)

# 3. 召回相关记忆
memories = client.memory.search(
    user_id="user_123",
    query="用户的回答偏好"
)
```
