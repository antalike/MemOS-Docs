## 1. MemOS スキル（Skills）とは何ですか？

**スキル（Skills）** は、Agent がタスクを実行する際に動的に呼び出せる**モジュール化された能力パッケージ**です。これは Agent によって対話コンテキストに基づいて自動的にスケジューリングされ、必要に応じて注入されるため、ユーザーによる手動介入は不要です。これらのスキルは通常、開発者がプログラミング大規模モデルと協調して、オープンソースプロジェクトまたはネイティブな構想に基づいて構築し、実際の使用過程で継続的に最適化されます。

MemOS は「記憶はすなわち資産」であると提唱しています。私たちは、実際の対話の中で蓄積された解決パスとユーザーの好みこそ、本質的に最も価値のあるスキル素材であると考えています。この理念に基づき、MemOS は**すでにユーザー記憶からスキルを自動抽出することをサポートしています**——散在するインタラクション履歴を、再利用可能でパーソナライズされた専門能力として固定化します。

::note
**MemOS スキルと既存の記憶にはどのような違いがありますか？**

* **静的事実 → 動的実行**

記憶は通常、静的で事実的なものです。たとえば、「私は上海に住んでいます」「私は簡潔な返信が好きです」といった情報であり、これらの情報は Agent の推論に必要なコンテキストを提供します。

一方、スキルは記憶の上に構築された実行可能な行動能力であり、たとえば「完全な旅行プランをどのように計画するか」のような明確なタスク処理ロジックのセットをカプセル化し、Agent の意思決定と行動を導きます。

* **断片化 → 構造化**

記憶は通常断片化されており、各項目は1つの事実または好みだけを記述します。

一方、スキルは高度に構造化されており、複数の関連する記憶を1つの完全なタスクプランに統合し、異なるタスクで再利用できます。
::

## 2. 動作原理

![image.png](https://cdn.memtensor.com.cn/img/1769653199709_6ol3n7_compressed.png)

上図は、エンドユーザー、あなたが構築した AI Agent、および MemOS の完全なインタラクションフローを示しています。

1.  `add/message` インターフェースを呼び出して、ユーザーの対話メッセージを MemOS に渡します。

2.  MemOS はリクエストを受信した後、以下の処理を順番に完了し、スキル（Skill）ファイルを生成します。

    a.  **インテリジェントスライシング**：履歴対話内のタスク境界を識別し、タスクテキストブロックに分割します。

    b.  **クラスタリング抽出**：同種のタスクテキストブロックをクラスタリングし、ユーザーの履歴記憶と組み合わせて、構造化されたスキルテキストを抽出します。

    c.  **スキル変換**：スキルを、実行可能で認識可能なスキル（Skill）ファイルに変換します。

3.  `search/memory` インターフェースを呼び出して記憶を検索すると、MemOS はコンテキストに関連するユーザー事実、好み、ツール記憶、および一致したスキル（Skill）ファイルを一括して返します。

4.  スキルファイルをダウンロードし、記憶とスキルファイルをまとめてあなた自身がデプロイした大規模モデルに渡すことで、長期経験と自動生成されたスキルを効果的に活用できます。

## 3. 使用例

以下では、MemOS が履歴対話に基づいて「旅行計画」スキルを生成する使用例を示します。

### 1. **メッセージを追加**

「高エネルギーJ人」と「旅行計画アシスタント」の対話内容を追加します。「高エネルギーJ人」は旅行計画に対していくつかの要件を表明しました。

*   戻り道が嫌い、弾丸旅行派

*   文化的な観光スポットが好き

*   事前に天気と気温を確認する必要がある

```
import os
import requests
import json

# あなたの API Key に置き換えてください
os.environ["MEMOS_API_KEY"] = "YOUR_API_KEY"
os.environ["MEMOS_BASE_URL"] = "https://memos.memtensor.cn/api/openmem/v1"

data = {
    "user_id": "memos_user_123",
    "conversation_id": "0127",
    "messages": [
      {"role": "user", "content": "来週成都に遊びに行くので、5日間の旅行プランを立ててください。私は戻り道をしない弾丸旅行が好きなので、道中で味わう価値のあるグルメも記載してください。"},
      {"role": "assistant", "content": "...ここでは省略..."},
      {"role": "user", "content": "私は文化的な観光スポットを巡るのが比較的好きで、ショッピングモールなどにはあまり興味がありません。"},
      {"role": "assistant", "content": "...ここでは省略..."},
      {"role": "user", "content": "計画する際には、事前に天気と気温も確認して、荷物の準備がしやすいようにしてください。"},
      {"role": "assistant", "content": "...ここでは省略..."}
    ]
  }
headers = {
  "Content-Type": "application/json",
  "Authorization": f"Token {os.environ['MEMOS_API_KEY']}"
}
url = f"{os.environ['MEMOS_BASE_URL']}/add/message"

res = requests.post(url=url, headers=headers, data=json.dumps(data))

print(f"result: {res.json()}")

```

### 2. **記憶を検索**

   このユーザーが再びアシスタントに旅行計画の要件を出したと仮定し、ユーザーの query を渡し、skill のリコールを有効にします。

   ```
   import os
   import requests
   import json
   
   # あなたの API Key に置き換えてください
   os.environ["MEMOS_API_KEY"] = "YOUR_API_KEY"
   os.environ["MEMOS_BASE_URL"] = "https://memos.memtensor.cn/api/openmem/v1"
   data = {
     "query": "清明節に雲南へ行く予定です。7日間の旅程を計画してください。",
     "user_id": "memos_user_123",
     "conversation_id": "0301",
     "include_skill": True # skill のリコールを有効化
   }
   headers = {
     "Content-Type": "application/json",
     "Authorization": f"Token {os.environ['MEMOS_API_KEY']}"
   }
   url = f"{os.environ['MEMOS_BASE_URL']}/search/memory"
   
   res = requests.post(url=url, headers=headers, data=json.dumps(data))
   
   print(f"result: {res.json()}")
   ```

### 4. **あなただけのスキルを構築**

MemOS は、異なるユーザーの対話メッセージに基づいて、その人専用のスキルを作成できます。たとえば、私たちは別途「低エネルギーP人」と「旅行計画アシスタント」の対話を構築しました。彼が次のように述べたときです。

*   夜型で、朝起きられない

*   あまり遠くなく、急いで移動する必要のある観光スポットには行きたくない

*   穴場スポットを織り交ぜ、ありきたりな道を歩まない

MemOS が構築したスキルファイルには次が含まれています。

*   午後から夜の外出で、詰め込みすぎない旅程を計画する

*   あまり遠くなく、急いで移動する必要のないルートを推薦する

*   穴場スポットを織り交ぜる。
