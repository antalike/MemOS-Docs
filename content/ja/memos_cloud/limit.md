## 1. クォータの説明

![image.png](https://cdn.memtensor.com.cn/img/1766481509513_5d4x8o_compressed.png)

MemOS クラウドサービスは現在、すべての開発者に対して無料版からエンタープライズ版までの複数の料金プランを提供しており、さまざまな規模のチームのニーズを満たします。現在、すべてのバージョンは期間限定で無料です。[MemOS 公式サイト-価格](https://memos.openmem.net/cn/pricing)へアクセスし、ご要望に合ったバージョンを申請してください。
今すぐ行動し、MemOS クラウドサービスがもたらす無限の可能性を享受して、あなたのプロジェクトの急速な成長を後押ししましょう！

::note
**注意**
- 利用枠は、各開発者アカウント配下のすべてのプロジェクトで共同して累計されます。
- リクエスト失敗（認証失敗、パラメータエラー、上限超過制限など）は**利用枠を消費しません**。
::

## 2. リソース制限

サービスの安定性と安全性を確保するため、MemOS クラウドサービスはコアインターフェース呼び出しに対して以下の制限を設けており、アカウント単位で計算されます：

| **インターフェース名**       | **単回入力上限**     | **単回出力上限** |
|----------------|------------------|--------------|
| addMessage     | 20,000 token     | -            |
| searchMemory   | 20,000 token     | 事実記憶：25 件<br>嗜好記憶：25 件<br>ツール記憶：25 件<br>スキル：25 件 |

また、ナレッジベース文書アップロード関連機能は現在、一律で単一ファイルあたり100MB、500ページ、20,000tokensを超えず、1回のアップロード総数は20個を超えないよう制限されています。
より高度または特別な要件がある場合は、プロジェクトチームまでご連絡のうえご相談ください。

::note
**注意**
- リクエストが単回上限を超えた場合、システムは直接対応するエラーコードを返し、呼び出し回数は減算されません。
- また、最大 QPS ≤ 50（つまり1秒あたり最大 50 回のリクエスト）を推奨します。これは厳格な制限ではありませんが、高並列リクエストはプラットフォームの処理能力の影響を受ける可能性があるため、実際の要件に応じて呼び出し頻度を適切に制御してください。
::
