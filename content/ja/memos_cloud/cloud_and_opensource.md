## 1. The MemOS Solution That Suits You Best

MemOS は AI アプリケーションに**2つ**の「記憶」ソリューションを提供し、迅速な検証から本番レベルのデプロイまで、あらゆるシナリオのニーズを満たします：

*   MemOS クラウドプラットフォーム —— 開発を簡素化し、容易に管理：5分以内にワンクリックでクラウドサービスを利用でき、AI アプリケーションの迅速な構築と反復に適しています。

*   MemOS オープンソースソリューション —— 自主デプロイ、完全制御：自社環境にデプロイし、業務要件に応じて二次開発と深い統合を行います。

*   **ハイブリッドデプロイモデル** —— 柔軟な組み合わせ：中核業務データはローカル化し、非機密シナリオはクラウドに接続して、コンプライアンスとコストを両立します。

> _クラウドサービスでもオープンソースフレームワークでも、MemOS はあなたの AI に永続的な記憶を簡単に持たせることができます。_


## 2. 機能比較

| 機能 | MemOS クラウドプラットフォーム | MemOS オープンソースソリューション |
|------|-------------|--------------|
| デプロイ難易度 | 非常に低い、5分で公開可能 | 自分で環境設定が必要 |
| データ保存場所 | クラウド（プライベート化を選択可能） | 完全ローカル |
| 無料枠 | あり | 無制限（セルフホスト） |
| カスタム LLM | 主流モデルをサポート | 任意のモデル |
| モニタリングとログ | コントロールコンソール内蔵 | 自分で統合が必要 |
| SLA 保証 | あり | なし |
| コミュニティサポート | あり | あり |
| 商用サポート | あり | なし |


## 3. 選択ガイド

### MemOS クラウドプラットフォームを選ぶ

*   **迅速な導入**：わずか数分で、あなたの AI アプリケーションに記憶を標準搭載できます。業務ロジックと機能実装に集中でき、複雑なストレージや記憶管理システムの保守に時間を費やす必要はありません。

*   **ゼロコスト検証**：十分な無料トライアル枠を提供し、最小コストでソリューションの実現可能性と製品効果を検証できます。

*   **ログとモニタリング**：コンソールで呼び出しログをリアルタイムに確認し、完全な呼び出しチェーン分析を取得できるため、デバッグ、モニタリング、パフォーマンス最適化に便利です。

### MemOS オープンソースソリューションを選ぶ

*   **データ主権**：すべての記憶データはあなたのプライベート環境に保存され、厳格なデータコンプライアンス要件を満たします。

*   **カスタム設定**：LLM プロバイダー、推論バックエンド、デプロイ戦略などを自由に選択でき、より高い柔軟性と制御性を実現します。

*   **コード拡張**：コードベースを直接修正し、必要に応じてカスタム機能を拡張し、改善内容をコミュニティに還元できます。

*   **オフラインデプロイ**：完全オフラインのイントラネット環境をサポートし、ネットワーク分離要件のあるシナリオに適しています。

### オープンソースソリューションに適さないシナリオ

> _チームに専任の運用担当者がいない場合、またはプロジェクトが初期検証段階にある場合は、クラウドプラットフォームを優先して使用することを推奨します。_


## 4. クイック導入例

クラウドプラットフォームへの接続は3ステップだけです：

```python
from memos import MemOSClient

# 1. クライアントを初期化
client = MemOSClient(api_key="your_api_key")

# 2. ユーザー記憶を作成
client.memory.add(
    user_id="user_123",
    content="ユーザーの好み：簡潔な回答スタイルが好き"
)

# 3. 関連記憶を想起
memories = client.memory.search(
    user_id="user_123",
    query="ユーザーの回答の好み"
)
```
