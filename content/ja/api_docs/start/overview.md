## 1. インターフェース紹介

MemOS は完全なインターフェースを提供しており、シンプルな API リクエストを通じて、記憶関連の機能をお客様の AI アプリケーション内に統合し、異なるユーザーと AI エージェントの記憶の生成、スケジューリング、想起、およびライフサイクル管理を実現できます。

::tip
**クイックスタート：** [**MemOS コンソール**](https://memos-dashboard.openmem.net/apikeys/) からあなたのインターフェースキーを取得し、1分で初回の記憶操作を完了できます。
::

## 2. 入門ガイド

以下の2つのシンプルなコアステップで MemOS API の使用を開始します：

*   [**メッセージを追加**](/api_docs/core/add_message)：ユーザー対話内の元のメッセージ内容を保存し、記憶を生成します；
    
*   [**記憶を検索**](/api_docs/core/search_memory)：ユーザーの関連する記憶断片を検索して想起し、モデルが生成する回答内容の参考を提供します。
    

## 3. インターフェース分類

MemOS が提供する豊富な機能インターフェースを探索します：

*   [**コアインターフェース**](/api_docs/core/add_message)：記憶のコア操作能力を提供し、記憶の生成から消費までの全プロセスを実現します。

*   [**メッセージ関連インターフェース**](/api_docs/message/add_feedback)：元のメッセージ内容データのアップロードと管理に使用されます。

*   [**知識ベース関連API**](/api_docs/knowledge/create_kb)：知識ベースおよびそのドキュメントのアップロードと管理に使用されます。


## 4. 認証

すべてのAPIリクエストには認証が必要です。リクエストヘッダーの `Authorization` にお客様のインターフェースキーを含めてください。[**MemOS コンソール**](https://memos-dashboard.openmem.net/apikeys/)からインターフェースキーを取得します。

::warning
クライアントまたは公開リポジトリでお客様のインターフェースキーを公開しないでください。すべてのリクエストは環境変数またはサーバーサイド呼び出しを通じて行う必要があります。
::

## 5. 次のステップ

*   👉 [**メッセージを追加**](/api_docs/core/add_message)：あなたの最初の記憶を生成します；
    
*   👉 [**記憶を検索**](/api_docs/core/search_memory)：記憶フィルターを使用して記憶の高度な検索を実現します。
