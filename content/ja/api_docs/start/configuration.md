---
title: プロジェクト設定
desc: MemOS は、プロジェクト単位でリソース、権限、および呼び出しログを管理することをサポートします。1つのプロジェクトは、1つの App、1つの Agent、またはリソースを独立して管理する必要がある任意のモジュールです。
---

## 1. 新規プロジェクトの作成

*   新規ユーザーごとに、デフォルトで1つの「デフォルトプロジェクト」を所有します。
    
*   コンソールで新規プロジェクトを作成する際に、名称と説明を入力すると、あなた専用の独立したプロジェクトを作成できます。
    

![image.png](https://cdn.memtensor.com.cn/img/1766024162978_5nsoul_compressed.png)

## 2. プロジェクトの削除

*   複数のプロジェクトを所有している場合、不要になったプロジェクトを削除できます。
    

::warning
プロジェクトを削除すると、そのプロジェクト配下のすべての記憶、メッセージ、および関連データが消去されます。この操作は**復元できません**。
::

![image.png](https://cdn.memtensor.com.cn/img/1766024215447_ywtqmb_compressed.png)

## 3. プロジェクト API キー

*   各プロジェクトは独立した API キーのリストを持ち、そのプロジェクト配下のすべての記憶、メッセージ、およびデータへのアクセスに使用されます。
    
*   コンソールの左上でプロジェクトを切り替えると、対応するキーを確認できます。
    

![image.png](https://cdn.memtensor.com.cn/img/1766024242682_flsty6_compressed.png)

## 4. プロジェクト呼び出しログ

*   コンソールの左上でプロジェクトを切り替えると、API 呼び出し状況と履歴を監視できます。
    

![image.png](https://cdn.memtensor.com.cn/img/1766024337178_5gwpgv_compressed.png)

## 5. プロジェクトナレッジベース

*   コンソールまたは API を通じてナレッジベースを作成し、本プロジェクトに関連付けられたナレッジベースを追加します。
    

::note
ナレッジベースの原理と使用方法については、[**ナレッジベース紹介ページ**](/memos_cloud/features/advanced/knowledge_base)にアクセスし、説明に従って、ユーザー記憶と一緒にリコールできるナレッジベース文書記憶を一歩ずつ作成してください。
::
