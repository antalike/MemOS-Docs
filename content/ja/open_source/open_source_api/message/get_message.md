**インターフェースパス**：`POST /product/get/message`
**機能説明**：このインターフェースは、指定した会話内のユーザーとアシスタントの元の対話記録を取得するために使用されます。要約情報を返す「メモリ」インターフェースとは異なり、このインターフェースが返すのは未加工の元テキストであり、チャット履歴の回顧機能を構築する中核インターフェースです。

## 1. メモリ (Memory) vs メッセージ (Message)

開発プロセスでは、以下の2種類のデータを区別してください：
* **メモリの取得 (`/get_memory`)**：システム処理後の**事実と嗜好の要約**を返します（例：「ユーザーは可視化に R 言語を使うのを好む」）。
* **メッセージの取得 (`/get_message`)**：**元の対話テキスト**を返します（例：「最近 R 言語を独学しているのですが、おすすめの可視化パッケージはありますか」）。

## 2. 主要インターフェースパラメータ
このインターフェースは以下のパラメータをサポートします：

| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| `user_id` | `str` | はい | - | メッセージ取得に関連付けられたユーザーの一意識別子。 |
| `conversation_id` | `str` | いいえ | `None` | 指定した会話の一意識別子。 |
| `message_limit_number` | `int` | いいえ | `6` | 返されるメッセージ数を制限します。推奨最大値は 50 です。 |
| `conversation_limit_number`| `int` | いいえ | `6` | 返される会話履歴数を制限します。 |
| `source` | `str` | いいえ | `None` | メッセージのソースチャネルを識別します。 |

## 3. 動作原理


1. **会話の特定**：システムは提供された `conversation_id` に基づいて、基盤ストレージ内からそのユーザーと会話に属するメッセージ記録を検索します。
2. **スライス処理**：`message_limit_number` パラメータに基づき、システムは最新のメッセージから逆順に指定件数を切り出し、返される内容が直近の対話であることを保証します。
3. **安全な分離**：すべてのリクエストは `RequestContextMiddleware` ミドルウェアを通過し、`user_id` の帰属権を厳格に検証して、権限を超えたアクセスを防止します。

## 4. クイックスタート例

オープンソース版に組み込まれている `MemOSClient` を使用して、対話履歴をすばやく取得します：

```python
from memos.api.client import MemOSClient

# クライアントを初期化
client = MemOSClient(
    api_key="YOUR_LOCAL_API_KEY",
    base_url="http://localhost:8000/product"
)

# 指定した会話の最近 10 件の対話記録を取得
res = client.get_message(
    user_id="memos_user_123",
    conversation_id="conv_r_study_001",
    message_limit_number=10
)

if res and res.code == 200:
    # 返されたメッセージリストを反復処理
    for msg in res.data:
        print(f"[{msg['role']}]: {msg['content']}")
```

## 5. 使用シナリオ
### 5.1 チャット UI 履歴の読み込み
ユーザーがある履歴会話をクリックして入るとき、このインターフェースを呼び出すことで対話の場面を復元できます。`message_limit_number` と組み合わせてページネーション読み込みを実装し、フロントエンド性能を向上させることを推奨します。

### 5.2 外部モデルへのコンテキスト注入
カスタムの大規模モデルロジック（MemOS 組み込みの chat インターフェースではない）を使用している場合、このインターフェースを通じて元の対話履歴を取得し、それを手動でモデルの messages 配列に連結できます。

### 5.3 メッセージの回顧分析
元の対話記録を定期的にエクスポートして、AI の返信品質の評価やユーザーの潜在的意図の分析に使用できます。
