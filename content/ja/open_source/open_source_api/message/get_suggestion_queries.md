# 提案質問の取得 (Get Suggestion Queries)

**インターフェースパス**：`POST /product/suggestions`
**機能説明**：このインターフェースは「あなたが聞きたいこと」機能を実現するために使用されます。システムは、提供された対話コンテキストまたは対象 **MemCube** 内の最近の記憶に基づいて、大規模言語モデルにより 3 つの関連する提案質問を生成し、ユーザーの対話継続を支援します。

## 1. コアメカニズム：デュアルモード生成戦略

**SuggestionHandler** は、入力パラメータの違いに応じて、2 つの柔軟な生成モードをサポートします：

* **対話ベースの即時提案 (Context-based)**：
    * **トリガー条件**：リクエストで `message`（対話履歴）が提供されている場合。
    * **ロジック**：システムは最近の対話内容を分析し、現在の話題に密接に関連する 3 つの後続質問を生成します。
* **記憶ベースの発見提案 (Memory-based)**：
    * **トリガー条件**：`message` が提供されていない場合。
    * **ロジック**：システムは `mem_cube_id` で指定された記憶体から「最近の記憶」を検索し、それに基づいてユーザーの最近の生活や仕事の状態に関連する発見的な質問を生成します。



## 2. 主要インターフェースパラメータ

コアパラメータの定義は以下のとおりです：

| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| **`user_id`** | `str` | はい | - | ユーザー一意識別子。 |
| **`mem_cube_id`** | `str` | はい | - | **コアパラメータ**：提案生成の根拠となる記憶空間を指定します。 |
| **`language`** | `str` | いいえ | `zh` | 提案生成に使用する言語：`zh` (中国語) または `en` (英語)。 |
| `message` | `list/str`| いいえ | - | 現在の対話コンテキスト。提供された場合、対話ベースの提案を生成します。 |

## 3. 動作原理 (SuggestionHandler)

1. **コンテキスト認識**：`SuggestionHandler` はまず `message` フィールドを確認します。値がある場合は対話の要点を抽出し、空の場合は下位の `MemCube` に切り替えて最近の動向を取得します。
2. **テンプレートマッチング**：システムは `language` パラメータに基づいて、組み込みの中国語・英語プロンプトテンプレート（Prompt Templates）を自動的に切り替えます。
3. **モデル推論**：LLM を呼び出して背景資料を推論し、生成される 3 つの質問が論理的であり、かつ示唆に富むことを保証します。
4. **整形出力**：提案質問を配列形式で返却し、フロントエンドがそのままクリックボタンとしてレンダリングしやすくします。

## 4. クイックスタート例

SDK を使用して、現在の対話に対する中国語の提案を取得します：

```python
from memos.api.client import MemOSClient

client = MemOSClient(api_key="...", base_url="...")

# シナリオ：「R言語」に関する直前の対話に基づいて提案を生成
res = client.get_suggestions(
    user_id="dev_user_01",
    mem_cube_id="private_cube_01",
    language="zh",
    message=[
        {"role": "user", "content": "R言語の可視化を学びたいです。"},
        {"role": "assistant", "content": "ggplot2 パッケージの学習をお勧めします。これは R言語可視化の中核ツールです。"}
    ]
)

if res and res.code == 200:
    # 出力例: ["ggplot2 はどのようにインストールしますか？", "定番の ggplot2 チュートリアルにはどのようなものがありますか？", "R言語には他にどのような可視化パッケージがありますか？"]
    print(f"提案質問: {res.data}")
```

## 5. 使用シナリオの提案
対話誘導：AI がユーザーに返信した後、このインターフェースを自動的に呼び出し、返信ボックスの下に提案ボタンを表示して、ユーザーがさらに深く議論できるよう誘導します。

コールドスタート活性化：ユーザーが新しいセッションに入り、まだ発言していない場合、「記憶ベースモード」により、ユーザーが関心を持つ可能性のある過去のトピックを表示し、沈黙を破ります。
