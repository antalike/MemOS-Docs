---
title: エラーコード
---

| エラーコード | 意味 | 推奨される解決方法 |
| :--- | :--- | :--- |
| **パラメータエラー** | | |
| 40000 | リクエストパラメータエラー | パラメータ名、型および形式が要件に適合しているか確認してください |
| 40001 | リクエストデータが存在しません | リソース ID（例: memory_id）が正しいか確認してください |
| 40002 | 必須パラメータを空にすることはできません | 不足している必須フィールドを補ってください |
| 40003 | パラメータが空です | 渡されたリストまたはオブジェクトが空でないか確認してください |
| 40006 | サポートされていない型 | type フィールドの値を確認してください |
| 40007 | サポートされていないファイル形式 | 許可された形式（.pdf, .docx, .doc, .txt）のみをアップロードしてください |
| 40008 | Base64 コンテンツが不正です | Base64 文字列に不正な文字が含まれていないか確認してください |
| 40009 | Base64 形式が不正です | Base64 エンコード形式が正しいか確認してください |
| 40010 | ユーザー ID が長すぎます | user_id の長さは 100 文字を超えることはできません |
| 40011 | セッション ID が長すぎます | conversation_id の長さは 100 文字を超えることはできません |
| 40020 | プロジェクト ID が不正です | Project ID の形式が正しいことを確認してください |
| **認証と権限エラー** | | |
| 40100 | API Key 認証が必要です | Header に有効な API Key を追加してください |
| 40130 | API Key 認証が必要です | Header に有効な API Key を追加してください |
| 40132 | API Key が無効または期限切れです | API Key の状態を確認するか、再生成してください |
| **クォータとレート制限エラー** | | |
| 40300 | インターフェース呼び出し回数の上限を超えました | <a href="/memos_cloud/limit#_4-领取更多额度" target="_blank">より多くのクォータを取得</a> |
| 40301 | リクエスト Token 呼び出し上限を超えました | 入力内容を減らすか、より多くのクォータを取得してください |
| 40302 | レスポンス Token 呼び出し上限を超えました | 想定出力を短くするか、より多くのクォータを取得してください |
| 40303 | 1 回の対話の長さが制限を超えました | 1 回の入力/出力の長さを短縮してください |
| 40304 | アカウント全体の API 呼び出し回数を使い切りました | <a href="/memos_cloud/limit#_4-领取更多额度" target="_blank">より多くのクォータを取得</a> |
| 40305 | 入力が 1 回あたりの Token 上限を超えました | 入力内容を短縮してください |
| 40306 | 記憶削除の認可に失敗しました | この記憶を削除する権限があるか確認してください |
| 40307 | 削除する記憶が存在しません | memory_id が有効か確認してください |
| 40308 | 削除する記憶に対応するユーザーが存在しません | user_id が正しいか確認してください |
| **システムとサービスエラー** | | |
| 50000 | システム内部例外 | サーバーがビジー状態または異常が発生しています。サポートに連絡してください |
| 50002 | 操作に失敗しました | 操作ロジックを確認するか、後でもう一度お試しください |
| 50004 | 記憶サービスは一時的に利用できません | 後で記憶の書き込み/取得操作を再試行してください |
| 50005 | 検索サービスは一時的に利用できません | 後で記憶検索操作を再試行してください |
| **ナレッジベースと操作エラー** | | |
| 50103 | ファイル数が制限を超えました | 1 回のアップロードでのファイル数は 20 個を超えないようにしてください |
| 50104 | 単一ファイルのサイズが制限を超えました | 単一ファイルが 100MB を超えないことを確認してください |
| 50105 | すべてのファイルの合計サイズが制限を超えました | 1 回のアップロードの合計サイズが 300MB を超えないことを確認してください |
| 50107 | ファイルアップロード形式が要件に適合していません | ファイル形式を確認して変更してください |
| 50120 | ナレッジベースが存在しません | ナレッジベース ID が正しいか確認してください |
| 50123 | ナレッジベースはこのプロジェクトに関連付けられていません | ナレッジベースが現在のプロジェクトに承認されているか確認してください |
| 50131 | タスクが存在しません | task_id が正しいか確認してください（処理状態の照会でよく見られます） |
| 50143 | 記憶の追加に失敗しました | アルゴリズムサービスの処理例外です。後でもう一度お試しください |
| 50144 | メッセージの追加に失敗しました | チャット履歴の保存に失敗しました |
| 50145 | フィードバックの保存および記憶への書き込みに失敗しました | フィードバック処理中に例外が発生しました |
