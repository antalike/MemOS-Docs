**インターフェースパス**：
* **完全応答**：`POST /product/chat/complete`
* **ストリーミング応答 (SSE)**：`POST /product/chat/stream`

**機能説明**：このインターフェースは MemOS の中核業務オーケストレーション入口です。指定された `readable_cube_ids` から関連記憶を自動的にリコールし、現在の文脈と組み合わせて応答を生成し、必要に応じて対話結果を `writable_cube_ids` に自動書き戻しして、AI アプリケーションの自己進化を実現します。


## 1. コアアーキテクチャ：ChatHandler オーケストレーションフロー

1. **記憶検索 (Retrieval)**：`readable_cube_ids` に基づいて **SearchHandler** を呼び出し、分離された Cube から関連する事実、嗜好、およびツール背景を抽出します。
2. **コンテキスト拡張生成 (Generation)**：検索された記憶断片を Prompt に注入し、指定された LLM（`model_name_or_path` を通じて）を呼び出して、対象に応じた応答を生成します。
3. **記憶自動クローズドループ (Storage)**：`add_message_on_answer=true` を有効にすると、システムは **AddHandler** を呼び出して今回の対話を指定された Cube に非同期保存し、開発者が追加インターフェースを手動で呼び出す必要はありません。
## 2. 主要インターフェースパラメータ

### 2.1 身元と文脈
| パラメータ名 | 型 | 必須 | 説明 |
| :--- | :--- | :--- | :--- |
| **`query`** | `str` | はい | ユーザーの現在の質問内容。 |
| **`user_id`** | `str` | はい | ユーザー一意識別子。認証とデータ分離に使用します。 |
| `history` | `list` | いいえ | 短期の履歴対話記録。現在のセッションの一貫性維持に使用します。 |
| `session_id` | `str` | いいえ | セッション ID。「ソフトシグナル」として、このセッション内の関連記憶のリコール重みを高めます。 |

### 2.2 MemCube 読み書き制御
| パラメータ名 | 型 | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| **`readable_cube_ids`** | `list` | - | **読み取り：** 検索を許可する記憶 Cube のリスト（個人ライブラリと公開ライブラリをまたいでも可）。 |
| **`writable_cube_ids`** | `list` | - | **書き込み：** 対話完了後、自動生成された記憶を保存すべき対象 Cube のリスト。 |
| **`add_message_on_answer`** | `bool` | `true` | 自動書き戻しを有効にするかどうか。記憶の継続的な更新を維持するため、有効化を推奨します。 |

### 2.3 アルゴリズムとモデル設定
| パラメータ名 | 型 | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| `mode` | `str` | `fast` | 検索モード：`fast` (高速)、`fine` (精細)、`mixture` (混合)。 |
| `model_name_or_path` | `str` | - | 使用する LLM モデル名またはパスを指定します。 |
| `system_prompt` | `str` | - | デフォルトのシステムプロンプトを上書きします。 |
| `temperature` | `float` | - | サンプリング温度。生成テキストの創造性を制御します。 |
| `threshold` | `float` | `0.5` | 記憶リコールの関連性しきい値。この値を下回る記憶は除外されます。 |

## 3. 動作原理

MemOS は、選択可能な 2 種類の応答モードを提供します：
### 3.1 完全応答 (`/complete`)
* **特徴**：モデルがすべての内容を生成した後、一度に JSON を返します。
* **シナリオ**：非対話型タスク、バックグラウンドロジック処理、またはリアルタイム性要求が低いシンプルなアプリケーション。

### 3.2 ストリーミング応答 (`/stream`)
* **特徴**：**Server-Sent Events (SSE)** プロトコルを採用し、Token をリアルタイムでプッシュします。
* **シナリオ**：チャットボット、インテリジェントアシスタントなど、即時のタイプライター風フィードバック効果を必要とする UI インタラクション。

## 4. クイックスタート

オープンソース版に組み込まれている `MemOSClient` を使用して呼び出すことを推奨します。以下の例は、R 言語学習に関する提案を問い合わせ、記憶機能を利用する方法を示しています：

```python
from memos.api.client import MemOSClient

client = MemOSClient(api_key="...", base_url="...")

# 対話リクエストを開始
res = client.chat(
    user_id="dev_user_01",
    query="以前の私の嗜好に基づいて、R 言語のデータクレンジング方案を一式推薦してください",
    readable_cube_ids=["private_cube_01", "public_kb_r_lang"], # 読み取り：個人嗜好+公開ライブラリ
    writable_cube_ids=["private_cube_01"],                      # 書き込み：個人空間に蓄積
    add_message_on_answer=True,                                 # 自動記憶書き戻しを有効化
    mode="fine"                                                 # 精細検索モードを使用
)

if res:
    print(f"AI 返信内容: {res.data}")
```
