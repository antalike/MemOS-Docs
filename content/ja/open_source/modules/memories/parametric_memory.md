`パラメトリックメモリ (Parametric Memory)` は、MemOS アーキテクチャにおける中核的な**長期知識および能力の担体**です。プレーンテキストメモリやアクティベーションメモリとは異なり、パラメトリックメモリは言語構造、世界知識、および汎用推論能力の深い表現をエンコードし、モデルの重みの中に直接埋め込みます。

MemOS のアーキテクチャ設計において、パラメトリックメモリは静的な事前学習済み重みに限定されるものではなく、**LoRA アダプター**やエキスパートプラグインモジュールなどのモジュール化された重みコンポーネントも含みます。これにより、モデル全体を再学習することなく、LLM の能力を段階的に拡張またはカスタマイズできます。

たとえば、構造化された、または固定された知識をパラメータ形式へと抽出し、それを独立した**能力モジュール (Capability Blocks)** として保存し、推論の過程で動的にロードまたはアンロードできます。これにより、法的推論、財務分析、または特定分野の要約などのタスク向けに「エキスパートサブモデル」を作成することが非常に容易になります——そしてそのすべては MemOS によって一元管理されます。

## 設計目標

::list{icon="ph:check-circle-duotone"}
-  **制御可能性** — 必要に応じたパラメータモジュールの生成、ロード、切り替え、または組み合わせをサポート。
-  **可塑性** — プレーンテキストメモリおよびアクティベーションメモリと協調して進化し、知識の抽出とロールバックをサポート。
-  **追跡可能性** *(開発中)* — パラメータモジュールのバージョン管理機能を提供。
::

## 現在の状態

`パラメトリックメモリ (Parametric Memory)` は現在、設計およびプロトタイプ検証段階にあります。今後のバージョンでは、パラメータモジュールの生成、圧縮、およびホットスワップのための API を公開する予定であり、マルチタスク、マルチロール、およびマルチエージェントアーキテクチャをより良くサポートすることを目指しています。

今後の更新にぜひご注目ください！

## 関連モジュール

パラメトリックメモリは開発中ですが、現在すでに次のものを試すことができます:
- **[GeneralTextMemory](/open_source/modules/memories/general_textual_memory)**: ベクトルベースの柔軟なセマンティックストレージ

## 開発者向け注意事項

パラメトリックメモリは、統一された **Memory³** アーキテクチャに関する MemOS のビジョンを完成させます:
- **パラメトリックメモリ**: 内在化され埋め込まれた暗黙知
- **アクティベーションメモリ**: 一時的なランタイム状態
- **プレーンテキストメモリ**: 構造化され、追跡可能な明示的外部メモリ

この三者の有機的な結合により、高い適応性、持続的な進化可能性、そして説明可能性を備えた知能システムが構築されます。
